## Providers

Provider setup is documented at [docs.twinny.dev](https://docs.twinny.dev/providers/overview/), one page per server:

- [Ollama](https://docs.twinny.dev/providers/ollama/)
- [LM Studio](https://docs.twinny.dev/providers/lm-studio/)
- [llama.cpp](https://docs.twinny.dev/providers/llama-cpp/)
- [Other local servers](https://docs.twinny.dev/providers/other-local-servers/) (Open WebUI, LiteLLM, text-generation-webui, QVAC, any OpenAI-compatible server)
- [Hosted APIs](https://docs.twinny.dev/providers/hosted-apis/)
- [Devices (P2P)](https://docs.twinny.dev/providers/devices/)
- [A team gateway](https://docs.twinny.dev/teams/connect/)

Which models suit completion, chat and embeddings, and which fill-in-the-middle template each uses, is on [Supported models](https://docs.twinny.dev/providers/supported-models/).
