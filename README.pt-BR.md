# Twinny

O Twinny é uma extensão gratuita de IA para o Visual Studio Code, com recursos avançados para auxiliar na programação.

## Provedores compatíveis

- API compatível com OpenAI/Ollama em localhost (padrão)
- [OpenAI](https://openai.com)
- [Anthropic](https://www.anthropic.com)
- [OpenRouter](https://openrouter.ai)
- [Deepseek](https://www.deepseek.com)
- [Cohere](https://www.cohere.ai)
- [Mistral AI](https://mistral.ai)
- [Perplexity](https://www.perplexity.ai)
- [Groq](https://groq.com)

## 🚀 Primeiros passos

Para consultar um guia rápido de início, acesse nossa [documentação](https://twinnydotdev.github.io/twinny-docs/).

## Principais recursos

### Autocompletar código no meio do arquivo
O Twinny oferece sugestões de código em tempo real com tecnologia de IA para facilitar a programação.

### Converse com a IA sobre seu código
Use a barra lateral para conversar com a IA sobre seu código e obter explicações, testes e sugestões de refatoração.

### Outros recursos
- Uso online e offline
- Endpoints de API personalizáveis
- Conversas preservadas
- Compatibilidade com o padrão da API da OpenAI
- Preenchimento no meio do código em uma ou várias linhas
- Modelos de prompt personalizáveis
- Geração de mensagens de commit do Git
- Instalação fácil pelo marketplace do VS Code
- Configurações personalizáveis (provedor de IA, modelo, porta e caminho)
- Aceitação direta de soluções de código
- Criação de novos documentos a partir de blocos de código
- Visualização lado a lado das diferenças
- Modo de chat em tela cheia
- Cópia de blocos de soluções de código
- Embeddings do workspace para assistência contextualizada

### Embeddings do workspace
O Twinny usa embeddings do workspace para oferecer assistência contextualizada, melhorando a relevância das sugestões.
